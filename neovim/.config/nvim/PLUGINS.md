# Plugins Quick Reference

## File Management
- **neo-tree** — Tree view for browsing and manipulating files (`:Neotree` or via fzf)

## Navigation & Search
- **fzf-lua** — Fuzzy finder for files, grep, buffers
- **harpoon2** — Quick navigation to marked files
- **telescope** — Fallback fuzzy finder with LSP integration
- **aerial** — Code outline sidebar

## Editing
- **mini-surround** — Add/delete/change surrounding pairs (brackets, quotes, etc.)
- **yanky** — Enhanced yank history with `:Yanky` command
- **text-case** — Change case (snake_case, camelCase, etc.)
- **dial** — Increment/decrement numbers, dates, booleans with `<C-a>` / `<C-x>`

## Code Understanding
- **treesitter-context** — Show function signature while scrolling
- **ufo** — Smart code folding with tree-sitter
  - `zR` = open all folds
  - `zM` = close all folds
  - `za` = toggle fold at cursor

## Git
- **gitsigns** — Git marks and hunks in the gutter
- **neogit** (via snacks) — Git TUI (`<leader>gg`)

## Testing & Debugging
- **test.core** — Run tests with `:Neotest run` / `:Neotest file`
- **nvim-dap** — Debugger with breakpoints and stepping (`<leader>d...`)

## AI
- **claudecode** — Claude Code in floating terminal (`<C-,>`)

## UI
- **snacks** — Dashboard, notifications, toggle terminal
- **bufferline** — Tab bar for open buffers
- **catppuccin** — Theme

## Languages Configured
TypeScript, Python, Go, Rust, JSON, YAML, Markdown, Dockerfile, SQL, Terraform, Tailwind, Astro, Svelte, Vue
